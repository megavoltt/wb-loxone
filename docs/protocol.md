# Протокол и настройки

Для тех, кто хочет подключить мост не к Loxone или написать что-то своё.

## WB → Loxone: UDP

Мост отправляет на `<miniserver>:<udp_port>` по одному пакету на изменение:

```
wb.<устройство>.<канал>=<число>
```

* `<устройство>` и `<канал>` — ID из MQTT, приведённые к латинице: кириллица
  транслитерируется, всё кроме `A–Z a–z 0–9 _ -` заменяется на `_`.
  `Терморегулятор/Температура в помещении` → `wb.Termoregulyator.Temperatura_v_pomeschenii`.
* События кнопок: `wb.<устройство>.Input_1_click`, `…_double`, `…_triple`,
  `…_long`. Импульс — два пакета, `=1` и через `pulse_ms` `=0`.
* Значения: числа как есть (точка — десятичный разделитель); `true/on` → `1`,
  `false/off` → `0`; RGB `R;G;B` → `BBBGGGRRR` в процентах (формат Loxone);
  текст, который не число, не отправляется.

Когда отправляется:

* при каждом изменении значения в MQTT;
* не чаще `throttle_ms` на канал — последнее значение отправляется по истечении
  окна, промежуточные пропускаются. Для `switch`, `alarm`, `pushbutton` и событий
  кнопок ограничения нет;
* раз в `resync_s` — все выбранные значения подряд.

## Loxone → WB: HTTP

```
GET /set/<ключ>/<устройство>/<канал>/<значение>
```

`<устройство>` и `<канал>` — исходные ID из MQTT в URL-кодировке. Мост
публикует значение в `/devices/<устройство>/controls/<канал>/on`.

| Ответ | Когда |
|---|---|
| `200 ok` | опубликовано |
| `403 неверный ключ` | ключ не совпал |
| `403 канал не выбран для Loxone` | канал не отмечен в интерфейсе |
| `403 канал только для чтения` | `readonly` в описании канала |
| `404 нет такого канала` | нет в MQTT |
| `400 не понял значение` | не число для числового канала |

Преобразование значения: для `switch`/`pushbutton`/`alarm` любое ненулевое → `1`;
для числовых — ограничение `min`/`max` канала; для `rgb` — `BBBGGGRRR` →
`R;G;B` (или `r;g;b` как есть); для `text` — строка как есть.

## Файл настроек

`/mnt/data/etc/wb-loxone.json`, другой путь — переменная окружения `WBLOX_CONFIG`.

| Ключ | По умолчанию | Что это |
|---|---|---|
| `miniserver` | `""` | IP Miniserver |
| `udp_port` | `7001` | порт виртуального входа UDP |
| `http_port` | `8099` | порт веб-интерфейса и команд (после смены — перезапуск службы) |
| `wb_host` | `""` | адрес WB в шаблонах; пусто — определяется по маршруту до Miniserver |
| `key` | случайный | ключ в адресе команд |
| `title` | `WirenBoard` | имя общего блока |
| `throttle_ms` | `500` | не чаще раза в N мс на канал |
| `resync_s` | `300` | полная пересылка раз в N с, `0` — выключить |
| `click_ms` | `250` | ожидание следующего нажатия серии |
| `long_ms` | `600` | порог долгого нажатия |
| `pulse_ms` | `150` | длительность импульса события |
| `button_log` | `false` | подробный журнал нажатий |
| `ui_password` | `""` | пароль веб-интерфейса (Basic Auth, имя любое) |
| `selected` | `{}` | выбранные каналы, `"устройство/канал": true` |
| `aliases` | `{}` | имена устройств для Loxone |

Переменные окружения: `WBLOX_MQTT_HOST` (по умолчанию `127.0.0.1`),
`WBLOX_MQTT_PORT` (`1883`).

## API веб-интерфейса

| Запрос | Что делает |
|---|---|
| `GET /api/state` | устройства, каналы, значения, настройки, счётчики |
| `POST /api/config` | изменить настройки (JSON с ключами из таблицы выше, кроме `key`) |
| `POST /api/newkey` | сгенерировать новый ключ команд |
| `POST /api/resync` | переслать все выбранные значения |
| `POST /api/test` | `{"dev","ctrl","value"}` — команда как от Loxone |
| `GET /template/viu.xml?dev=<id>` | шаблон входов устройства (без `dev` — общий) |
| `GET /template/vo.xml?dev=<id>` | шаблон выходов устройства (без `dev` — общий) |
| `GET /template/all.zip` | все шаблоны по устройствам |

Если задан `ui_password`, все запросы, кроме `/set/…`, требуют Basic Auth.

## Устройство моста

Один файл `wbloxone.py`, только стандартная библиотека Python 3.9:

* свой клиент MQTT 3.1.1 (QoS 0), подписка на `/devices/#`;
* модель устройств и каналов из топиков `meta` (новый JSON-формат и старые
  отдельные топики `meta/type`, `meta/readonly`…);
* распознавание нажатий — класс `Buttons`, шаг `step(now)` не зависит от
  реального времени и покрыт тестами (`tests/`);
* HTTP-сервер для интерфейса, команд и шаблонов.

Стеки всех потоков в журнал — `kill -USR1 $(systemctl show -p MainPID --value wb-loxone)`.
