ключ команд: Шаблоны всех устройств (ZIP) Общий VIU Общий VO
Как подключить в Loxone Config
  1. Задайте IP Miniserver и сохраните. Отметьте ниже нужные каналы — выбор сохраняется сразу.
  2. Шаблоны делаются на каждое устройство отдельно, как в MegaFlex: блок в Loxone называется именем устройства (поле «Имя в Loxone»), файлы VIU_Имя.xml и VO_Имя.xml. Скачать — кнопками VIU / VO у устройства или все сразу архивом ZIP.
  3. Положите файлы в Документы\Loxone\Loxone Config\Templates\VirtualIn (VIU_) и …\VirtualOut (VO_), либо импортируйте: Периферия → Виртуальные входы → Импорт шаблона (и так же для Виртуальных выходов).
  4. Перетащите нужные входы/выходы на страницу программы и сохраните в Miniserver.
  5. Значения приходят по UDP сразу при изменении; раз в «Полную пересылку» мост повторяет все — Loxone подхватит их после перезагрузки.
  6. Кнопки. У каждого входа со счётчиком (Input N + Input N counter) есть каналы «одинарное», «двойное», «тройное», «долгое» — импульс 1→0. Число нажатий берётся из аппаратного счётчика модуля, поэтому короткие нажатия не теряются даже на медленной шине. Удержание для диммирования и жалюзи — обычный канал Input N. Одинарное приходит через «Ожидание след. нажатия» после отпускания.
  7. RGB: выход Loxone (BBBGGGRRR, %) переводится в R;G;B WB автоматически. Диммеры и уставки — аналоговые выходы <v>.
  8. После изменения выбора каналов шаблон нужно импортировать заново — Loxone добавит недостающие команды в существующий блок с тем же именем, если импортировать его поверх.

Команды Loxone приходят на http://WB:порт/set/ключ/устройство/канал/значение. Без верного ключа и для невыбранных каналов команды отклоняются.
