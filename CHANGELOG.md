# Что нового

## Unreleased

## 1.4.2 — 2026-11-23

* Исправлено «фантомное» периодическое нажатие Zigbee-кнопки: полный resync
  (каждые `resync_s`, по умолчанию 300 с, и после сохранения настроек)
  повторял последнее значение событийного текстового канала `action`, и
  Loxone принимал его за новое нажатие. Событийные текстовые каналы при
  resync больше не пересылаются; состояния (режимы, статусы) по-прежнему
  восстанавливаются после перезагрузки Miniserver.
* Документация: английский перевод всех страниц `docs/` — [docs/en/](docs/en/);
  исправлено устаревшее утверждение в `docs/wirenboard.md` о текстовых каналах
  (с версии 1.4.0 они передаются в Loxone).

## 1.4.1 — 2026-11-22

* Установка через apt-репозиторий: GitHub Actions собирает пакет `wb-loxone`
  по тегам и публикует его на https://megavoltt.github.io/wb-loxone/
  (ветка `apt` + GitHub Pages). Обновления на контроллере — обычным
  `apt upgrade`. `install.sh` остается как альтернатива.
* Исправлены потери и задержки нажатий Zigbee (текстовый канал `action`):
  повторное нажатие с тем же значением подряд больше не пропадает (модель
  считала его дублем), события не проходят окно троттлинга (задержка до
  `throttle_ms` и перезапись ожидающего значения теряли быстрые нажатия).
* Документация: раздел «Zigbee-кнопки и выключатели (zigbee2mqtt)» в
  `docs/loxone.md` — как текстовый канал `action` превращается в цифровые
  входы и почему шаблон нужно пересоздавать после появления новых значений.

## 1.4.0 — 2026-11-22

* Текстовые каналы (действия кнопок, режимы, статусы) теперь доходят до
  Loxone: значение отправляется в UDP как есть, а в шаблоне канал
  разворачивается в цифровые входы — по одному на каждое известное значение.
  Мост знает типовые значения по имени канала и запоминает новые в конфиге
  (`textvals`); в веб-интерфейсе у текстового канала виден список значений,
  попадающих в шаблон. Требуется переэкспорт шаблона после обновления.
* Веб-интерфейс на русском и английском: язык определяется из браузера,
  переключатель в шапке, выбор запоминается. Строки интерфейса переехали
  во встроенные словари `I18N` в `index.html` — новый язык добавляется
  одним ключом словаря. Имена устройств и каналов из MQTT не переводятся.
* Английский README приведён к полному паритету с русским.
